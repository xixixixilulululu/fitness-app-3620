# Visual Asset Provenance

## Fictional trainer portraits

The three trainer portraits were generated specifically for this classroom project with OpenAI’s built-in image-generation tool on November 18, 2026. They depict fictional people, not real trainers or real transformation cases. The transparent originals were resized to 512×512 PNGs for efficient Android use.

| Profile | Android resource |
|---|---|
| Maya Chen | `app/src/main/res/drawable-nodpi/trainer_maya.png` |
| Jordan Brooks | `app/src/main/res/drawable-nodpi/trainer_jordan.png` |
| Alex Rivera | `app/src/main/res/drawable-nodpi/trainer_alex.png` |

## Plan Builder icons

The Plan Builder icons are original project-local Android vector drawables, not raster or third-party stock artwork. They live in `app/src/main/res/drawable`, use shared semantic colors, and cover all 31 selectable choices while preserving visible text labels.
